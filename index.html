🔑 How to Make Yourself the First Admin in Firebase

Because the /admins collection can only be modified by existing Admins or via the Firebase Console, follow these 3 steps to grant your account Admin rights:

  1. Make sure you are signed in to PlatePlan. Your Firebase User UID is shown below:
Not signed in — please Sign In first
  1. Open your Firebase Firestore Data tab and click "+ Start collection" (or select the admins collection).
  2. Set Collection ID to admins, paste your UID as the Document ID, add a field role = "admin", and click Save. Then click Refresh Admin Status below!
