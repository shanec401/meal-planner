      🔥 Firebase Auth & Firestore Database Setup

      To enable real cloud login (Google & Username/Password) and cross-device Firestore database saving on GitHub Pages, paste your Firebase Web App configuration below or edit firebase-config.js.

      1. Go to Firebase Console → Create a project → Add a Web App (</>).
      2. In Authentication → Sign-in method, enable Email/Password and Google.
      3. In Authentication → Settings → Authorized domains, add your GitHub Pages domain (yourusername.github.io).
      4. In Firestore Database, create a database so users' meal plans and custom recipes are stored under users/{uid}.
